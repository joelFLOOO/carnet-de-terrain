# Carnet de terrain

Outil de saisie d'observations pour le suivi d'élevages piscicoles
et avicoles à Douala.

**Démo :** https://joelfloo.github.io/carnet-de-terrain/

## Le problème
Les relevés de terrain se font sur papier, puis se ressaisissent le
soir. Double travail, pertes, erreurs de recopie.

## Ce que fait l'outil
Saisie directe sur téléphone ou PC, calcul automatique de l'effectif
total et moyen, données conservées d'une session à l'autre.

## Construit avec
HTML, CSS, JavaScript — sans aucune bibliothèque externe.
